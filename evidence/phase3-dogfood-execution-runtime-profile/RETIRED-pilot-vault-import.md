# The pilot-vault-import receipts here cannot be reproduced

Five receipts in this directory carry the prefix `phase4-pilot-vault-import-` and name the
command `pnpm --dir TCRN-AOS phase4:pilot-vault-import-proof`, which no longer exists. The
script was retired under `TCRN-AOS-INC-002`: it read a 102-file package under a sibling
`TCRN Workflow` directory that was archived to a private Legacy repository and deleted on
2026-07-20, and its assertions are pinned to that package's exact file count.

The other receipts in this directory are current. `d3-*` and `d4-*` are regenerated by
`pnpm d3:real-dogfood-workload-proof` and `pnpm d4:friction-capture-proof`, which both
pass — run `pnpm d2:runtime-profile-activation-proof` first, as they fail closed without
an activated D2 profile root.

Reasoning in full: `docs/retired-proof-scripts.md`.
